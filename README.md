# claude-code-kotlin-practice

Practicing Claude Code with a small Kotlin/Android UI project.

This repo is where I'm practicing using Claude Code by building a small,
self-contained Android UI concept for garden/greenhouse layout planning
(placing pots, boxes, and greenhouses to scale, understanding size
commitment before buying or building).

It will eventually feed into a larger app,
[Garden_app_sandbox](https://github.com/ARaveala/Garden_app_sandbox), as a
concept for its user interface.

A few individuals will test this to see whether the interface offers any
real use, and to help surface backend needs for the larger project.

Expect rough edges, this is a learning space, not production code.
