# claude-code-kotlin-practice

Practicing Claude Code with a small Kotlin/Android UI project

This repo is where I'm practicing using Claude Code building a small, self contained Android UI concept (pot/greenhouse layout planning). 
That will eventually feed into a larger app [https://github.com/ARaveala/Garden_app_sandbox] as concept for a user interface.

This will be tested by a few individuals , to see if there is any actual use for something the interface would offer, and to help understand some backend needs.

Expect rough edges; this is a learning space, not production code.
